Portfolio Website is this site: a single-page portfolio built with Next.js and exported as static HTML, so it deploys to GitHub Pages with no server. [image:homepage.png:The page] covers experience, selected projects and a short about block.

## Key Features

### File-Based Content
Experience, projects and accomplishments are folders of plain text: a `metadata.txt` of key-value lines and a markdown `description.txt`, with media alongside under `public/media`. `featured.txt` in each section is the allow-list of what is published, so entries can stay on disk without appearing on the site.

### Static Export
`next build` renders everything at build time. A GitHub Actions workflow builds on every push to `main` and publishes the `out/` directory to GitHub Pages, with the base path injected so the same workflow serves a user site or a project site.

### Theming
Light and dark mode keyed off CSS tokens, with the saved choice replayed by an inline script before first paint so there is no flash.

## Technologies & Skills

- Next.js, React, TypeScript
- GitHub Actions, GitHub Pages
