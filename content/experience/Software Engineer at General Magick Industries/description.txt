I work on **MagickMind**, General Magick Industries' AI agent infrastructure platform, where I own the agent runtime and the inference path end to end — not a single service, but the whole vertical slice a request travels through.

## What I own

### Agent supervisor
I built the supervisor that runs each agent as an isolated process with its own minted credentials, so agents join a workspace as real participants and every action is attributable to a specific agent rather than to one shared orchestrator.

### Reasoning service
I refactored the reasoning service and implemented frontier reasoning methods — RLM, Lambda-RLM and Mixture of Judges — which lifted benchmark accuracy by roughly 20% over calling a model directly.

### Inference path
I shipped native tool calling and mid-turn escalation from a fast model to a frontier model, replacing brittle text-parsed tool calls across the gateway, the reasoning service and the supervisor.

### Agent memory
I refactored the episodic memory flow that gives agents recall across conversations.

## Performance work

Two numbers I care about:

- **Agent turn latency: 4s to 2.5s.** I engineered the execution loop to cache and persist only where it actually pays off.
- **Fast-path inference latency: down 40%.** Achieved by reworking how the reasoning service assembles and dispatches requests.

## Open source
