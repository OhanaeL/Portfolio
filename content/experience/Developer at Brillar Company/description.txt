At Brillar (Atenxion) I was an Associate Fullstack Engineer on a remote team in Singapore, owning AI-focused Python microservices end to end: architecture, implementation and production operations.

## My responsibilities

- **Two Python microservices**, owned end to end, built with FastAPI.
- **Document processing and web crawling pipelines** that turn files and pages into text for LLM workflows, using Docling for extraction.
- **The CRM integration service**, one backend that connects SalesIQ, Chatwoot and Zoho so every product shares the same integration instead of writing its own.

## Getting documents into the model

Most of the product's value came from what the model could read. The ingestion service takes uploads and crawled pages, extracts text with Docling, and hands clean chunks to the RAG and MCP-server services that the AI-driven UI widgets sit on top of.

## Operating it

Container build and startup time dropped **30%** after Docker optimisation, which mattered for weekly releases. I added **OpenTelemetry and Grafana** so every service reports latency and memory, and kept the **pytest** suites in CI/CD green so those releases stayed stable. Reviewing other teams' integrations against the shared CRM service was part of the job.
