# My Portfolio Website

This is my personal portfolio website showcasing my projects, accomplishments, and professional journey. Built with Flask, it features a beautiful dark purple theme with pixel art-inspired design elements.

## About This Portfolio

I've created this portfolio to showcase my work, achievements, and skills in a clean, modern way. The site dynamically generates pages from organized folders, making it easy to add new content without touching code.

## Tech Stack

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, JavaScript
- **Styling**: Custom CSS with CSS variables for easy theming
- **Icons**: Font Awesome

## Structure

The portfolio is organized into several main sections:

- **Projects**: Showcasing my technical work and applications
- **Timeline**: My journey and accomplishments over the years
- **Experience**: Professional roles, hackathon wins, and other experiences
- **About**: Personal background and technical skills

## Design Philosophy

I wanted a portfolio that reflects my personality - modern, clean, and with a touch of retro gaming aesthetics. The dark theme with purple accents creates a professional yet distinctive look that stands out while remaining readable and accessible.
