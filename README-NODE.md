# Node.js Integration Guide

This project now includes Node.js support for building and bundling JavaScript assets.

## Setup

1. Install Node.js dependencies:
```bash
npm install
```

## Development

For development, you have two options:

### Option 1: Use Vite dev server (recommended for JS development)
```bash
npm run dev
```
This starts Vite on port 5173 with hot module replacement. The Vite server proxies Flask requests to `http://localhost:5000`.

### Option 2: Use Flask directly (current setup)
```bash
python app.py
```
Flask will serve the source JavaScript files directly from `static/js/`.

## Building for Production

Build optimized JavaScript bundles:
```bash
npm run build
```

This creates optimized files in `static/dist/`. Flask will automatically detect and serve these built files if they exist.

## Adding npm Packages

You can now install npm packages:

```bash
npm install <package-name>
```

Then import them in your JavaScript files:
```javascript
import { someFunction } from 'package-name';
```

## Project Structure

- `static/js/` - Source JavaScript files (ES6 modules)
- `static/dist/` - Built/bundled JavaScript (generated by `npm run build`)
- `package.json` - Node.js dependencies and scripts
- `vite.config.js` - Vite build configuration

## Deployment

For production deployment, make sure to:
1. Run `npm run build` before deploying
2. Include `static/dist/` in your deployment
3. Flask will automatically use built files if they exist
