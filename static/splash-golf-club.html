SPLASH Golf Club is a Next.js web application I developed for golf club management and booking, which won 1st Place at the CIMSO ERP Hackathon. Built with Next.js 15 and TypeScript, the application provides real-time tee time bookings, member management, and integrates with CIMSO ERP systems for hotel and restaurant services. A companion Flutter mobile app extends the functionality to mobile devices.

Key Features

Golf Course Booking System

Multi-step booking flow supporting 9-hole and 18-hole bookings with real-time availability. Dynamic pricing adjusts based on the day of the week, and each course includes detailed hole information.

AI-Powered Chat Widget

Google Gemini-powered chatbot provides intelligent assistance for booking inquiries and course information through natural language interaction.

Admin Dashboard

Comprehensive dashboard with analytics, revenue charts, booking statistics, and user management tools for complete platform control.

Technologies & Skills

  • Next.js 15: React framework with App Router for server-side rendering
  • TypeScript: Type-safe development
  • React Query: Data fetching and caching
  • Google Generative AI: AI-powered chat functionality
  • Tailwind CSS: Utility-first CSS framework

Development Approach

Developed as a hackathon entry focusing on production-ready features. The modular architecture integrates with external CIMSO ERP systems while maintaining clean separation of concerns. Multi-language support and AI integration enhance accessibility and user interaction.
