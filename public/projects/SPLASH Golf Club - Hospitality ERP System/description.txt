SPLASH Golf Club is a React-based golf club management system I developed that won **1st Place** out of 20+ teams at the CIMSO Hospitality ERP Hackathon 2025. The system is integrated with CIMSO's ERP and features an AI-powered multilingual, voice-enabled chatbot to automate booking workflows and enhance user experience. [image:homepage.png:The application] provides real-time tee time bookings, member management, and integrates with CIMSO ERP systems for hotel and restaurant services.

## Key Features

### Golf Course Booking System
Multi-step booking flow supporting 9-hole and 18-hole bookings with real-time availability. Dynamic pricing adjusts based on the day of the week, and each course includes detailed hole information.

### AI-Powered Chat Widget
[image:chatpanel.png:Google Gemini-powered chatbot] provides intelligent assistance for booking inquiries and course information through natural language interaction.

### Admin Dashboard
Comprehensive dashboard with analytics, revenue charts, booking statistics, and user management tools for complete platform control.

## Technologies & Skills

- HTML, CSS, JavaScript: Core web technologies
- React: Frontend framework for building the user interface
- Axios: HTTP client for API communication
- Tailwind CSS: Utility-first CSS framework
- Google Generative AI: AI-powered multilingual, voice-enabled chatbot functionality

## Development Approach

Developed as a hackathon entry focusing on production-ready features. The modular architecture integrates with external CIMSO ERP systems while maintaining clean separation of concerns. Multi-language support and AI integration enhance accessibility and user interaction.
