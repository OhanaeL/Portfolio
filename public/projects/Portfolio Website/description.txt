The main idea was to make it easy to add content. Adding a new project is just creating a folder, dropping in a description file and some images, and it's live. No code changes needed. I can control which projects show up first using a simple order.txt file, so I can highlight my best work without messing around in templates.

I spent a lot of time on the details that make browsing smooth. There's real-time search that filters as you type, and tag filters that automatically appear based on what I tag each project with. When writing descriptions, I can use Markdown for formatting, which is much nicer than plain text. I also built a hover feature where you can hover over text and see an image preview - [image:homepage.png:like this] - useful for showing screenshots without cluttering up the page.

The whole thing runs on Flask with vanilla JavaScript. Everything's file-based, which means I can update my projects, accomplishments, or about page just by editing text files. No database migrations, no admin panels, just simple files.

[image:projects_page.png:The projects page] includes all the search and filtering functionality. The timeline page shows accomplishments over the years, and the about page has my skills visualized with animated progress bars.

Building this was as much about learning as it was about having a portfolio. I got to experiment with CSS variables (all the colors are defined at the top, which makes theming easy), work on responsive design, and figure out how to make file-based content management work smoothly.
