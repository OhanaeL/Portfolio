# Public Content Folder

This folder contains all the dynamic content for your portfolio website.

## Structure

```
public/
├── projects/        # Your project pages
├── accomplishments/ # Your journey/timeline entries
└── about/          # Your about me content
```

## How to Use

All your portfolio content is organized in these subfolders:

### Projects (`projects/`)
Add folders for each project with:
- `description.txt` - Project description
- `images/` - Project images
- `metadata.txt` - Project metadata (date, tags, team, description)
- `embeds/` - Videos and PDFs

See `projects/README.md` for detailed instructions.

### Journey/Accomplishments (`accomplishments/`)
Add folders for timeline entries with:
- `description.txt` - Achievement description
- `images/` - Images for the entry
- `embeds/` - Videos and PDFs
- `order.txt` - Control the display order

See `accomplishments/README.md` for detailed instructions.

### About Me (`about/`)
Add your personal information:
- `*.txt` files - Each becomes a section
- `info.txt` - Name and birthdate
- `skills.csv` - Your skills data
- `resume.pdf` - Your resume
- `profile.png` - Profile picture
- `certificates/` - Your certificates
- `order.txt` - Control section order

See the individual README files in each folder for more details.
